### 3.1.0—1.21.x
* Split 1.21.5-1.21.11 into three separate version ranges to account for API differences across minor versions

* Fixed a crash on 1.21.6–1.21.8 caused by an input API that was not available until 1.21.9

### 3.0.0—1.21.x
* Added multi-version support covering Minecraft 1.21 through 1.21.11
* Replaced per-slot numerical countdown timers with progress bars
* Reduced server refresh interval from 1000ms to 100ms, eliminating the visible delay when cooked food disappears from the GUI
### 2.0.0—1.21.11
* Updated to Minecraft 1.21.11
* Fixed per-slot cooking timers to tick down independently on the client side, eliminating the visual sync where all timers updated simultaneously every second

* Initial Release
